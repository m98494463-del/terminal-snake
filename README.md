# Terminal Snake 🐍

بازی مار رنگی برای ترمینال، نوشته‌شده با پایتون خالص (فقط کتابخانهٔ استاندارد `curses`).

## ویژگی‌ها

- گرافیک رنگی در ترمینال با سر و بدنهٔ متمایز
- غذای معمولی `@@` (۱۰ امتیاز) و غذای طلایی `$$` (۳۰ امتیاز) که بعد از مدتی چشمک می‌زند و ناپدید می‌شود
- سیستم مرحله: هر ۵۰ امتیاز، یک مرحله بالاتر و سرعت بیشتر
- ذخیرهٔ بهترین امتیاز در `~/.terminal_snake.json`
- حالت `--wrap`: عبور از دیواره‌ها و ظاهر شدن از سمت دیگر
- مکث، شروع دوباره، و سازگاری با اندازهٔ ترمینال
- منطق بازی جدا از رابط کاربری و همراه با تست

## اجرا

```bash
git clone https://github.com/m98494463-del/terminal-snake.git
cd terminal-snake
python snake.py          # حالت عادی
python snake.py --wrap   # عبور از دیواره‌ها
```

در ویندوز ابتدا نصب کنید: `pip install windows-curses`

## کنترل‌ها

| کلید | کار |
|---|---|
| جهت‌نماها یا W A S D | حرکت |
| P یا Space | مکث |
| R | بازی دوباره (پس از باخت) |
| Q | خروج |

## تست‌ها

```bash
pip install pytest
pytest
```

## ساختار

- `snake_engine.py` — منطق بازی (حرکت، برخورد، امتیاز، مرحله)
- `snake.py` — رابط ترمینال با `curses`
- `tests/` — تست‌های واحد
